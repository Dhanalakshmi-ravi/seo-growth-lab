KEYWORD RESEARCH

Keyword Research for Beginners

Learn how to understand what people search for and organize keywords around search intent.

KEYWORD TYPES

Common Keyword Categories

Short-Tail Keywords

Broad searches such as "SEO" or "shoes".

Long-Tail Keywords

More specific searches such as "technical SEO checklist for beginners".

Primary Keywords

The main topic or search query a page is primarily designed to address.

Secondary Keywords

Related terms that help cover the topic comprehensively.

SEARCH INTENT

Understand Why Someone Searches

Informational

The user wants to learn something.

Example: What is technical SEO?

Navigational

The user wants to reach a particular website or page.

Example: Google Search Console

Commercial

The user is researching options before making a decision.

Example: Best SEO tools

Transactional

The user is ready to take an action such as buying or signing up.

Example: Buy SEO course
